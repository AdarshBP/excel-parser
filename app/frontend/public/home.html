What Excel Parser does

Config-driven parsing

Define your schema in a configuration workbook — table names, column types, row ranges. The parser reads exactly what you configure, nothing more.

Multiple sources

Load workbooks from local files, Google Sheets links, or Google Drive. Batch mode processes multiple files against one config in a single run.

Schema preview

See your generated tables as an ER diagram, preview data rows with type casting, and catch validation issues before pushing anything.

Strict data quality

Type mismatches and missing required columns block the push. Every row carries its source file, sheet, and row number for traceability.

Google Drive integration

Connect your Google account, pick files with the native Google Picker, and the app downloads and parses them automatically. Read-only access only.

PostgreSQL output

Data lands in PostgreSQL with proper types, indexes on key columns, and full load audit trail. Each file gets a unique file_id for lineage.
