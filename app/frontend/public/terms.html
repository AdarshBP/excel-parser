Service description

Excel Parser is a configuration-driven tool that reads Excel and CSV workbooks and loads their contents into a database. It is provided as-is for internal business use.

Google API usage

Excel Parser uses Google APIs solely to:

  • Authenticate your Google account (OAuth 2.0) for Drive file access.
  • Read files you explicitly select through the Google Picker (read-only scope).

The app requests only the minimum scopes needed: drive.readonly and userinfo.email. No write access to your Drive is requested or possible.
